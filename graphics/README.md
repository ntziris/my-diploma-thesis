# Figures and editable graphics

The complete graphics collection from the submitted supplementary material:
124 SVG files and two EDDX projects. Filenames and file contents are preserved.

- [Figures](figures/) contains illustrations, diagrams, cover studies and page layout examples.
- [Source drawings](raw_figures/) contains the accompanying working drawings.
- [Application logo](logo%20of%20dApp.svg) contains the application artwork.

SVG files can be opened and edited in Inkscape. EDDX files are Edraw project
files included in the original graphics collection.

The page layout drawings document the thesis design. The reusable Typst
package is maintained in [ntua-thesis-template-greek](https://github.com/ntziris/ntua-thesis-template-greek).
