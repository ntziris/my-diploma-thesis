# Τοπική πύλη Walrus Sites

Η διεπαφή δημοσιεύεται ως Walrus Site, δηλαδή τα αρχεία της ζουν στο Walrus και
το αντικείμενο που τα περιγράφει ζει στο SUI. Ένας περιηγητής δεν ξέρει να τα
διαβάσει μόνος του. Χρειάζεται μια *πύλη*, η οποία επιλύει το subdomain σε
αναγνωριστικό αντικειμένου, διαβάζει από την αλυσίδα τα blob ids και κατεβάζει τα
αρχεία από το Walrus.

Το testnet δεν διαθέτει δημόσια πύλη. Η μοναδική πύλη τρίτου που υπήρχε,
`buildonwalrus.dev`, έπαψε να λειτουργεί τον Ιούλιο του 2026 και το domain
βγήκε προς πώληση. Επομένως την πύλη τη σηκώνουμε εμείς.

Αυτό δεν αποδυναμώνει την αποκέντρωση. Η πύλη δεν κατέχει τίποτε, ούτε τα
αρχεία ούτε το όνομα, και δεν συμμετέχει καθόλου μετά τη φόρτωση. Το ότι μπορεί
οποιοσδήποτε να τρέξει δική του είναι ακριβώς η εγγύηση, όχι υποχώρηση.

## Εκτέλεση

```sh
docker compose up -d
```

Η πύλη ακούει στο `http://localhost:3000`. Ένας ιστότοπος ανοίγει με το
αναγνωριστικό του αντικειμένου σε βάση 36 ως subdomain:

```
http://<b36-object-id>.localhost:3000
```

Το αναγνωριστικό σε βάση 36 το τυπώνει το `site-builder` μετά τη δημοσίευση και
το κρατά στο `ws-resources.json`. Χωρίς όνομα SuiNS αυτός είναι ο μόνος τρόπος
πρόσβασης, και ο λόγος που η βάση 36 επιλέχθηκε είναι τα όρια του DNS. Ένα
subdomain δέχεται έως 63 χαρακτήρες και δεν διακρίνει πεζά από κεφαλαία, οπότε
τα 64 δεκαεξαδικά ψηφία ενός αναγνωριστικού δεν χωρούν, ενώ οι 50 χαρακτήρες
της βάσης 36 χωρούν.

Έλεγχος ότι σηκώθηκε:

```sh
docker compose logs -f
```

## Αρχεία

| Αρχείο | Ρόλος |
| --- | --- |
| `docker-compose.yml` | Η υπηρεσία, με την εικόνα και το mount της ρύθμισης |
| `portal-config.yaml` | Δίκτυο, RPC, aggregator, πακέτο Walrus Sites |

Δεν υπάρχει αντίγραφο του κώδικα της πύλης εδώ. Χρησιμοποιείται η επίσημη
εικόνα `mysten/walrus-sites-server-portal`.

## Δύο παγίδες

**Η ετικέτα της εικόνας λέει `mainnet`, η ρύθμιση λέει `testnet`.** Δεν είναι
λάθος. Η εικόνα είναι μόνο κώδικας Bun και διαβάζει το `portal-config.yaml` στο
runtime. Τα testnet tags στο Docker Hub έχουν μείνει στον Ιούλιο του 2025, οπότε
η νεότερη mainnet εικόνα με testnet ρύθμιση είναι η σωστή επιλογή.

**Ένα 404 δεν σημαίνει απαραίτητα σφάλμα της πύλης.** Αν τα logs δείχνουν
`Blob not available on aggregator (likely expired)`, η επίλυση πέτυχε και αυτό
που έληξε είναι η αποθήκευση στο Walrus. Τότε ο ιστότοπος θέλει επαναδημοσίευση
με περισσότερες εποχές.
