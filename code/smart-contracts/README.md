# Έξυπνα Συμβόλαια (Smart Contracts)

Αυτός ο φάκελος περιέχει τον πυρήνα της λογικής της εφαρμογής, γραμμένο στη
γλώσσα **Sui Move**.

## Περιεχόμενα
* Κανόνες δημιουργίας (minting) και μεταβίβασης έργων τέχνης.
* Λογική κλασματικής ιδιοκτησίας (fractionalization) και ελεύθερης αγοράς.
* Μητρώα για την πιστοποίηση των γκαλερί και των εξωτερικών πηγών (oracles).
* Έλεγχος δικαιωμάτων παρακολούθησης (royalties) από τις μεταπωλήσεις.
* Αρχεία μονάδων ελέγχου (unit tests) για την επαλήθευση της ορθότητας.

## Τοπικές δοκιμές

Με εγκατεστημένο το Sui CLI, από τον παρόντα φάκελο:

```bash
sui move test
```

Η σουίτα περιλαμβάνει 89 δοκιμές. Η εντολή μεταγλωττίζει το πακέτο και
ελέγχει τοπικά τις περιπτώσεις του `tests/`, χωρίς δημοσίευση στο δίκτυο.
Η τοπική εξάρτηση `../enclave/move/enclave` πρέπει να διατηρείται στη θέση
της μέσα στη δομή των παραδοτέων.
